Auto-Configure

One click, the app detects your location and configures city, units, and interval automatically. No accounts, no manual entry.

Or pick your region
1. City Location

Enter a city name (e.g. Seoul, New York) or a numeric OpenWeatherMap City ID for an exact match. To find a City ID: search on old.openweathermap.org/find and copy the number from the result URL.

2. Unit Format
3. Weather Update Interval

Default is 20 minutes. With your own API key you can use shorter intervals.

minutes
4. Current Weather API Key

OpenWeatherMap key for current conditions. Free registration at openweathermap.org/api. New keys take 1–2 hours to activate.

Clear removes your custom key. The device may fall back to its built-in shared key, if weather stops working, reboot the device from App Settings.
5. Forecast API Key

Separate key for weather forecast data. The public key may run out, set your own for reliability.

Clear removes your custom key. If forecast stops working after clearing, reboot the device from App Settings.
6. Weather Screen GIF Animation

Upload animated GIFs displayed on the weather screen (stored as 80×80 px on device). You can upload any size, the app will resize to 80×80 automatically.

WiFi Lock - Force PC to Stay on Device Network
WiFi lock inactive

When enabled, the app will monitor your PC's WiFi connection and automatically reconnect to the target network if it drifts. Ethernet adapters are temporarily disabled while the lock is active to prevent your PC routing traffic through Ethernet instead of WiFi (Ethernet takes priority by default in Windows and can silently break the connection to the device).

How to find your device IP
  1. Make sure your PC and device are on the same WiFi (2.4 GHz only)
  2. Check your router's device list - look for GIFTV
  3. Or open the original GeekMagic app and note the IP shown there
  4. Paste just the IP address above (e.g. 192.168.1.42)

About This App

A native Windows desktop controller for the GeekMagic SmallTV-Ultra. The device ships with a browser-based web UI served directly from the device, this app ports those same HTTP endpoints into a persistent, feature-rich desktop experience with image editing, WiFi lock, firmware management, and one-click weather configuration. All device commands are identical to what the official web UI sends; nothing is reverse-engineered.

About the Device

ESP8266 MCU · 240×240 IPS display · Built-in WiFi (2.4 GHz) · USB-C powered
